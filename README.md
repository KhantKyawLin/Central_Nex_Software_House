# 🏢 Central_Nex Software House - Official Website

This repository contains the source code for the official website of **Central_Nex Software House**. The site serves as a digital storefront to showcase our expertise in delivering high-quality web and mobile development solutions.

## 🌐 Live Website
The site is deployed and can be viewed at: **[centralnex.vercel.app](https://centralnex.vercel.app)**

## ✨ Key Features
- **Service Showcase:** Highlights our core offerings in Full-Stack Web Development and Mobile App Development.
- **Responsive Layout:** Optimized for a seamless viewing experience on desktops, tablets, and smartphones.
- **Modern UI:** A clean and professional design that reflects our commitment to technical excellence.
- **Fast Performance:** Optimized assets for quick load times and smooth navigation.

## 🛠 Tech Stack
- **Frontend:** Pure HTML5, Vanilla CSS3, and JavaScript (ES6+).
- **Deployment:** Vercel for high-performance hosting and continuous integration.

## 📂 Project Structure
- [index.html](cci:7://file:///d:/KKL_PORTFOLIO/index.html:0:0-0:0): The main structural entry point of the website.
- `style.css`: Contains all custom styling rules and responsive media queries.
- `script.js`: Handles interactive elements and dynamic site behavior.
- `image/`: Directory for all optimized visual assets and branding.
